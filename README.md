# DS-160 Intake — своя анкета с автоматической отправкой на почту

Это твой собственный сайт: клиент заполняет анкету на своём языке, прикладывает фото/скан паспорта,
жмёт «Отправить» — и тебе на почту сразу приходит письмо с PDF-сводкой всех ответов и вложенными файлами.
Никакой регистрации у клиента, никакого стороннего конструктора форм.

## Что внутри
- `index.html` — сам сайт (анкета на RU/EN/RO)
- `api/submit.js` — серверная функция, которая формирует PDF и отправляет письмо
- `api/_sections.js` — список разделов и вопросов (используется для подписи полей в PDF)
- `package.json` — список зависимостей

## Разовая настройка (займёт 15–20 минут)

### 1. Завести почтовый сервис для отправки писем
1. Зайди на **resend.com** и зарегистрируйся на свою рабочую почту.
2. В разделе **API Keys** создай новый ключ, скопируй его — он понадобится на шаге 3.
3. Домен подтверждать не нужно: раз получатель писем — это твой же аккаунт, отправка будет работать сразу.

### 2. Выложить код на GitHub
1. Зарегистрируйся на **github.com**, если ещё нет аккаунта.
2. Создай новый пустой репозиторий (например, `ds160-intake`).
3. Загрузи туда все файлы из этой папки (кнопка «Add file → Upload files» на странице репозитория — можно просто перетащить всю папку).

### 3. Развернуть сайт на Vercel
1. Зайди на **vercel.com**, войди через свой GitHub-аккаунт.
2. Нажми **Add New → Project**, выбери репозиторий `ds160-intake`.
3. В настройках проекта (**Environment Variables**) добавь две переменные:
   - `RESEND_API_KEY` — ключ из шага 1
   - `NOTIFY_EMAIL` — почта, куда должны приходить заявки (твоя)
4. Нажми **Deploy**. Через минуту получишь ссылку вида `ds160-intake.vercel.app` — это и есть твой сайт.

### 4. Проверить
Открой ссылку, заполни анкету как тестовый клиент на любом языке, прикрепи любое фото, нажми «Отправить».
Письмо с PDF и вложением должно прийти на почту, указанную в `NOTIFY_EMAIL`, в течение минуты.

### 5. (по желанию) Свой домен
В настройках проекта на Vercel можно привязать собственный домен (например, `anketa.тво-сайт.com`) —
покупается у любого регистратора, стоит недорого, подключается за пару кликов.

## Дальше
- Ссылку на сайт рассылаешь клиентам напрямую — в мессенджерах, на сайте, в объявлениях.
- Никакого обслуживания не требует: Vercel и Resend бесплатны для такого объёма (Resend — до 3000 писем в месяц).
- Если нужно добавить остальные вопросы официальной DS-160 (полный список — около 40 доп. вопросов
  в разделе безопасности, предыдущие работодатели за 5 лет и т.д.) — структура уже это позволяет,
  это просто добавление полей в массив `SECTIONS` в `index.html` и `api/_sections.js`.
- Файлы с ответами нигде не сохраняются на сервере — они целиком уходят в письмо. Если понадобится
  архив всех заявок (не только в почте), можно позже добавить базу данных — но для старта это не обязательно.
